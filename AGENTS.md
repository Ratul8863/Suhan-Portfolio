## Learned User Preferences
- Gives visual feedback in Banglish with screenshots or videos; treat phrases like "thik moto hoy ni" or "dekho kivabe thakbe" as a request to match the attached reference, not to invent a new layout.
- Expects pixel-perfect Figma implementation: placement, font color and size, hover states, and real phone layouts (~390px) as well as desktop — verified in the browser, not a loosely inspired layout.
- For motion, reproduce reference videos with high fidelity (sequence, direction, timing, easing, scale, rotation); do not loosely inspire the animation.
- Featuring projects follow Kala Web Studio (`trykala.com`): scroll-pinned horizontal track plus pointer-driven 3D depth/perspective and a circular VIEW PROJECTS cursor — not a carousel, card grid, or loose approximation; fix the existing section rather than rebuilding it. Keep project card frames uniform in width/height; VIEW PROJECT / card clicks open live external URLs, not internal detail pages. The circular VIEW PROJECT cursor still appears when full-motion/FX is off; section title/date entrance from the left should run when that section enters view. While that circular cursor is active, suppress the site-wide liquid trail.
- Site-wide pointer follows Kala (`trykala.com`): instant `+` crosshair plus a white velocity-driven liquid brushstroke trail (lags, stretches, contracts; idle blob sits behind the crosshair) — not a generic comet/dot trail or large default circle. Hide it on zones marked `data-liquid-cursor-hide` (e.g. All Projects archive) and wherever a section-owned circular cursor takes over. Over interactive buttons, disable the liquid trail and `+` crosshair — keep only the idle circle/blob.
- All Projects archive hover follows Dennis Snellenberg archive (`dennissnellenberg.com/archive`): large circular 3D cursor labeled `Website ↗` (not View Project); mild magnetic text lag that stays inside the ball; hovered row fades with title/meta split shift — match attached screenshots/videos. On small devices, match Figma all-projects layout node `700:29`.
- Reuse the existing shared Navbar and Footer (`SidebarNav` + `SiteFooter` via the public layout); never add page-local copies. Mobile nav motion follows Dennis Snellenberg (curved right-edge reveal/close, hamburger↔circular X morph, route/social interactions) while keeping this site's labels, styling, and desktop sidebar — black chrome, not purple; do not copy Dennis typography or layout.
- Do not use `overflow-x: hidden` as a layout fix; avoid custom overflow/scrollbar chrome that other sites do not show; download Figma assets locally (no temp URLs); keep Figma copy exact; flag font substitutions instead of silently swapping.
- Homepage hero hover is a liquid cursor-reactive mask synchronized across the full hero stage: over the portrait it reveals skull/helmet layers; outside the portrait it shows the ash/gray treatment with the same circling blob. Idle portrait stays the clean Figma state with no ghost-helmet or wireframe overlay; do not swap whole hero frames, and keep the background name and intro static. The Shots card is removed from the hero. Hero ambient should morph/flow like Lando Norris (`landonorris.com`) — no static SVG contour lines. On small screens, the hero is full-viewport (no next section peeking); match Figma mobile hero and tap-to-lock icon (`537:31`); tap-to-lock freezes scroll for the mask, then unlock restores scrolling. Extend the existing WebGL/SVG motion system rather than rebuilding it.
- First-load intro is a black fullscreen multilingual greeting (Osmo-style); exit with a Dennis Snellenberg-style curved curtain that pulls the homepage upward and settles it with no bounce/overshoot and no pause after the last greeting. Sidebar slides in with the curtain; nav labels must not appear before that slide-in. Do not jump to the footer, and preserve scroll position on reload.
- Sidebar nav links fill from the bottom and exit upward with a curved water-drop motion in one smooth layer; the label grows and the arrow moves but stays inside the button. Footer section links grow, shift slightly, and move their icon the same way. Book A Call and contact Submit share the Originkit liquid-carve button, and the carve should start promptly.
- Keep the site visually clean and light; heavy FX must stay optional via the full-motion toggle (default reduced) so lower-spec machines do not lag.
